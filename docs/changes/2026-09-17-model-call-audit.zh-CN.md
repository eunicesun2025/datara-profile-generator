# 模型调用链复审：提示词一致性、网络重试与深度思考

本次复审以 `62548a0` 为基线，重点覆盖模型设置、AI 分析、测试提取、提示词优化、预览和导出。不是对任意网络环境可用性的保证。

## 发现与修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 测试提取重新生成提示词，优化器使用活动版本 | 导入完整提示词后两个入口可能测试不同内容 | 保存后的预览、测试、导出统一使用活动版本；测试记录实际版本 ID 和哈希；未保存的提示词修改需先保存 |
| 普通任务只使用默认模型 | 优化评估使用 extraction_model，普通测试却可能调用其他模型 | 提取使用 extraction_model，AI 分析使用 optimizer_model，留空回退默认模型 |
| 重试循环分散，普通测试没有覆盖整个重试过程的总超时 | 后续修复容易遗漏入口、等待时间可能超出设置 | 所有入口复用 provider.completion_with_attempts，取消直接传播，总超时包含退避和重试 |
| 连接诊断只测默认模型且不重试 | 连接测试成功不能说明另外两个模型可用 | 去重检查默认、优化、提取模型，各自报告文本连接结果并复用重试策略 |
| 深度思考参数没有界面入口，保存时丢失 | 无法明确控制耗时与思考行为 | 增加自动、开启、关闭；保存、重开、刷新均保留；对新任务生效 |
| 开启思考仍固定使用非流式请求 | 部分 Qwen 模型拒绝该组合 | 显式开启时使用 SSE，只合并最终答案，忽略 reasoning_content；检测截断、断流、无答案 |
| 优化任务每次调用读取当前密钥 | 中途改设置会影响后续迭代 | 使用任务隔离的内存密钥快照，不落盘 |
| 网络异常原文写入日志 | 代理异常可能包含敏感连接信息 | 保留异常类型，不记录异常原文 |

## 行为约定

- 建立连接失败最多尝试两次；HTTP 429/500/502/503/504 最多三次。等待总量仍受配置的 timeout 限制。
- 响应超时不自动重复完整大请求；认证、证书、明确代理配置错误不盲目重试。
- timeout 是一次逻辑请求的总上限，不是整次优化的上限。基线、分析、候选评估和最终验证分别产生请求。
- 深度思考为全局设置，覆盖分析、优化、测试及连接诊断。自动模式保持原有行为：官方 DashScope 的 Qwen 3.8 Max/Flash 关闭思考，其余不传该参数。
- 显式开启/关闭发送 enable_thinking=true/false，供应商和网关必须支持。纯思考模型不一定能关闭思考；程序不会自动篡改用户的显式选择。
- 思考开启时使用流式传输，但界面仍在完整答案收到后显示结果，不展示思维链。
- 连接诊断仅验证文本调用；视觉能力需用样本进行提取验证。
- 尚未保存的编辑仍可预览生成结果；保存后才解析为活动版本，进行最终预览、测试和导出。

阿里云官方说明部分模型只支持流式思考，且思考 token 会增加耗时和费用：
[深度思考模型用法](https://www.alibabacloud.com/help/zh/model-studio/deep-thinking)。

## 验证

- 完整 pytest 回归：146 项通过（2 条第三方依赖弃用警告）；前端语法检查和 git diff --check 通过。新增 HTTPX MockTransport 跨入口测试，覆盖三种思考设置、连接失败后恢复、正确模型路由、优化全过程及运行中设置变更。
- 额外覆盖 SSE 合并、截断、断流、只有思考没有答案、非法成功响应、取消传播、含退避的总期限及日志敏感信息。
- 验证导入提示词在测试请求、预览、ZIP 导出中一致，且记录的哈希等于活动版本哈希。
- Playwright 在独立临时数据目录验证控件开启/关闭、保存和刷新后的恢复。

## 尚未验证与限制

- 本次未向真实 Qwen/Kimi 或企业网关发送付费请求；模拟网络测试不能证明真实账号、地域、代理、CA、模型能力或额度正确。
- 优化失败后会保留已有记录和候选，但没有完整断点续跑。修正连接后需要重新发起；满足现有缓存规则的基线可复用，最终验证仍需执行。
- 深度思考不能替代网络修复；永久配置问题必须修正配置。流式接口不受企业网关支持时会失败，不会悄悄关闭思考。
- 现有常驻服务需要重启才能加载后端修改。后续偶发错误优化的重复实测与历史证据分离方案，见 `2026-09-17-intermittent-optimization.zh-CN.md`。

后续修改网络调用时，应同时运行 `tests/test_provider.py`、`tests/test_app.py` 和 `tests/test_optimizer.py`，特别保留跨入口的三态测试，避免只修复一个调用方。

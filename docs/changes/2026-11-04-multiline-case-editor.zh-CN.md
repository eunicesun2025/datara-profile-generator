# 多行明细案例录入

提示词优化的新增案例、编辑正确答案和编辑历史错误现在提供逐行表格。子表可以添加或删除明细行，主表仍为单条记录。高级 JSON 编辑与表格同步，仍沿用原有 API 和存储格式。

操作：勾选待优化字段，上传案例，按原单顺序添加全部明细，逐行取消 null 并填写金额；没有现金的客户行保留 null，不删除该客户行。小计、合计不添加为明细。金额 0 与 null 分开保存，String 编号保留前导零。非法数字或布尔文本会阻止保存和增删行，避免静默提交上一个有效值。

历史错误可直接粘贴真实 JSON 或按字段模板逐行输入。历史错误应保留模型原本的行数和顺序，不自动复制正确答案，不自动补齐漏行。留空仍不提交历史错误；可清空已保存的历史错误。

当前比较逻辑仍按数组位置逐行对比，不自动按客户编号匹配。正确答案应包含完整的明细顺序。多列时可横向滚动；未提供的字段与显式 null 区别保留，不因表格渲染自动补字段。复杂或不规则结构可继续使用 JSON 编辑。

验证：172 项既有 Python 回归测试通过；隔离数据目录内以合成数据进行真实浏览器验证，覆盖五行回显、第 4 行 null、添加第 6 行填 0、保存重开、前导零保留、删除行、非法金额阻止保存、历史错误六行 JSON 导入与保存重开。此验证不代表真实视觉模型识别精度测试。
